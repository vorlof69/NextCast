# NextCast 6.1.0

Forever-native rotation engine for **WoW Forever 1–30**.

No TellMeWhen. No Action. No MetaEngine macros.

## Download

[https://github.com/vorlof69/NextCast/releases/latest](https://github.com/vorlof69/NextCast/releases/latest)

Direct: https://github.com/vorlof69/NextCast/releases/download/v6.1.0/NextCast-6.1.0.zip

1. Extract, rename the folder to `NextCast` if it has a suffix
2. `World of Warcraft\_classic_beta_\Interface\AddOns\`
3. `/reload`
4. `/nc`

## Healing

GGLoader clicks ExtraIcon ST and presses the **raw spell** on the scanned bar. NextCast snaps the heal target onto `@target` (Action TargetColor + `TargetUnit`), then restores the enemy after the press.

MotW / Thorns / heals **do not fire in Bear or Cat** — stay in form. Drop form once out of combat if you want the buff.

## Overview

Two tabs: **Overview** (spec + switches) and **Abilities**. Role is detected from talents and form.

`/nc` `/nc cd` `/nc aoe` `/nc kick` `/nc burst` `/nc queue NAME` `/nc ggl` `/nc reset` `/nc log`
